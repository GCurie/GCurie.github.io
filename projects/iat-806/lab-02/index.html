Lab 02 — Bouncing Ball

A short description of what this sketch does.

Notes

The github repo link is here.

A bouncing ball and square(ball?) using javascript and p5.js. The ball bounces off the edges of the canvas and changes color when it hits a wall! Each quadrant that the ball is in gets a different colour! The square ball gets a randomly assigned colour every frame (I'm calling it my square disco), and both the ball and square leave a trail behind them. When you click on the canvas (mousePressed), the ball changes its speed and direction.
